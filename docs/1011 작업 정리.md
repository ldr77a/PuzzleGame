   - 설정 → 개인정보 보호 및 보안 → **개발자 모드**

## 3. 결정할 것 (작업 4에서 사용)

### A. 배수 레시피

예를 들어 목표가 빨강 2 + 파랑 1(3방울)이라면:

- **(a) 비율만 맞으면 클리어 (지금):** 빨강 4 + 파랑 2(6방울)로도 클리어됩니다. 화면에 "방울 6/3"이 떠 있는데 클리어되는 셈입니다.
- **(b) 방울 수까지 정확히 맞아야 클리어 (추천):** "방울 3/3"이고 색이 맞을 때만 클리어됩니다. 방울이 넘치면 "방울이 너무 많아요"라는 안내가 뜨고, 되돌리기나 처음부터로 복구합니다. 게이트에도 같은 규칙을 적용합니다.
- 추천 이유
  - 화면에 항상 보이는 방울 수와 클리어 조건이 일치합니다.
  - 4×4 판에서 3방울 목표로 최단 6\~8걸음인 판은 (a) 규칙에서 후보가 0개였습니다. 같은 걸음 수로 배수를 먹는 길이 거의 항상 생기기 때문입니다. (b)에서는 배수로 먹는 길이 클리어가 아니므로, 이런 판도 쓸 수 있습니다.

### B. 게이트 통과 방식

10번 스테이지의 문 주변 (`문` = 게이트, `S` = 시작):

```
B  R  Y  B  Y
R  #  문 #  R
#  B  S  R  #
```

- **(a) 문 칸에 멈춰 섬 (지금):** 주황을 만든 뒤 S에서 위로 가면 문 칸에 서고, 문이 색을 가져갑니다. 여기서 아래로 내려오면 **색만 비워진 채 S로 돌아옵니다.** 문을 리셋 칸처럼 쓸 수 있습니다.
- **(b) 문을 지나 반대편 칸까지 한 번에 (추천):** S에서 위로 스와이프하면 문을 지나 바로 위 Y 칸에 도착하고 Y를 먹습니다. 되돌아가려면 문 색을 다시 만들어야 합니다.
  - 스와이프 한 번이라 1걸음으로 셉니다.
  - 문 너머가 벽이나 판 밖이면 그 방향으로는 지나갈 수 없습니다.
  - 10\~13번은 최단 걸음이 바뀔 수 있어서, 에이전트가 숫자를 다시 계산합니다.
- 추천 이유: 기획서에서 폐지한 리셋 칸이 문을 통해 다시 생기는 것을 막습니다. "문 = 다음 구역으로 가는 길"이라는 의미도 분명해집니다.

### C. 재시작하면 되돌리기 3회를 다시 채울지

- **(a) 다시 채움 (지금, 추천):** 스테이지를 나갔다 다시 들어오면 어차피 채워지므로, 재시작만 막는 것은 의미가 없습니다.
- **(b) 스테이지에 새로 들어올 때만 채움:** 재시작해도 남은 횟수가 그대로입니다.
