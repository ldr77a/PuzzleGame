# 작업 정리: 2026-10-17 (1017)

어제 꾸미기 작업에서 남은 작은 문제를 고치고, 2단계 남은 일(카멜리 그림, 튜토리얼 안내)을 상의할 시안을 만든 날입니다.

---

## 1. 고친 것

| 문제 | 수정 |
|---|---|
| 7번 스테이지 안내가 "짙은 회색 칸은 벽이에요"로 남아 있음 (벽이 울타리로 바뀌었는데) | "나무 울타리는 벽이에요. 지나갈 수 없어요." |
| 울타리에서 가로대가 판자 옆 테두리를 덮어, 가로대와 판자가 선 없이 맞닿음 | 가로대 위에 판자 테두리 층을 하나 더 그림. 바깥 테두리의 절반 두께라 판자 사이 틈으로 가로대가 계속 보임 |
| 밤에 힌트를 다 쓰고 다음 날 앱으로 돌아오면 버튼이 아직 [광고 보고 힌트]로 보임 (누르면 무료 힌트가 제대로 쓰이긴 함) | 앱으로 돌아올 때 화면 글자를 다시 읽음 |

화면 명세 14, 15절에 반영했습니다.

## 2. 검증

| 대상 | 결과 |
|---|---|
| 검증 3개 | 코어 58/58, 컴파일 OK ×3, 스테이지 49개 OK |

| 7번 안내 글자 | 주아 글꼴에 모두 있음 |
