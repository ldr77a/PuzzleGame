# 작업 정리: 2026-10-18 (1018)

앱 아이콘에서 카멜리가 배경과 따로 노는 문제를 상의하다가, 카멜리 선을 게임 전체에서 연하고 가늘게 바꾼 날입니다.

---

## 1. 카멜리 선

| 질문 | 결정 |
|---|---|
| 선 색 | 먹색 `#1E2B25` → 진초록 `#2B4A33` |
| 선 두께 | 그림 칸의 4.5% → 3.15%(30% 가늘게). 눈, 입, 눈 위 선도 같은 비율 |
| 몸 색 | 그대로(게임에서 섞인 색으로 물듦) |

- 시안 Q7의 5번(진초록 얇은 선) 그림을 보고 "연한 느낌과 얇은 느낌"으로 바꾸기로 했습니다. 지금 선이 너무 진하다는 의견이었습니다.
- `Tools/CameliArt/cameli.js`의 선 색과 두께를 바꾸고 레이어 PNG를 다시 뽑았습니다. 선과 얼굴 5장이 바뀌었고 채움 2장은 그대로입니다.
- 선이 가늘어진 만큼 발 바닥이 올라가서, 통통 뛸 때 찌그러지는 중심(`CameliFigure.Feet`)을 아래에서 23% → 24%로 옮겼습니다.
- 판 위, 타이틀, 말풍선의 카멜리가 모두 바뀝니다(모두 같은 PNG를 씀).
- 앱 아이콘 파일은 다시 뽑지 않았습니다. 아이콘은 아래 3절에서 다시 정하는 중이라 그때 함께 뽑습니다.
- 화면 명세 19, 20절에 반영했습니다.
