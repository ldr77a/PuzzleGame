# 플레이테스트 기록지

지인 5명 이상에게 프로토타입 스테이지 1\~13을 설명 없이 플레이하게 하고, 기획서 12절 합격 기준을 판정하기 위한 기록지입니다.

작성일: 2026-10-12

---

## 1. 준비물과 사전 점검

### 1.1 체크리스트

| 확인 | 항목 |
|---|---|
| [ ] | 최신 빌드가 폰에 설치되어 있다 (Android 또는 iPhone, 폰 한 대를 돌려 씀) |
| [ ] | 폰이 충분히 충전되어 있다 (충전기도 챙기기) |
| [ ] | 개발자가 미리 해 본 기록이 남아 있으면, 앱을 지우고 다시 설치해서 기록과 테스터 번호를 비웠다 |
| [ ] | 첫 테스터 전에 "다음 테스터"를 한 번 눌러 진행과 별을 비웠다 (아래 1.2) |
| [ ] | 조용하고 방해받지 않는 장소다 |
| [ ] | 한 사람당 20\~30분을 잡아 두었다 |
| [ ] | 이 기록지를 사람 수만큼 준비했다 (종이 또는 노트북) |

### 1.2 앱 안의 도구 (진행자만 사용)

- **플레이테스트 창 열기:** 위쪽 바의 스테이지 이름을 2초 동안 길게 누릅니다. "플레이테스트" 창이 뜨고 버튼이 세 개 있습니다.

| 버튼 | 하는 일 |
|---|---|
| 다음 테스터 | 실수 방지를 위해 **두 번** 눌러야 실행됩니다. 진행 중인 판을 기록에 남기고, 모든 진행과 별을 지운 뒤 1번 스테이지로 돌아갑니다. 테스터 번호가 1 올라갑니다. 지금 테스터의 기록이 하나도 없으면 번호는 그대로입니다. 기록 파일은 지워지지 않습니다. |
| 기록 보기 | 테스터별 요약을 보여 줍니다: 테스터 번호, 클리어 수(/13), 튜토리얼 1\~5번 모두 클리어 여부, 되돌리기 합계, 재시작 합계, 플레이 시간(분) |
| 닫기 | 창을 닫습니다. |

- **자동 기록:** 스테이지 시도마다 앱 저장 폴더(persistentDataPath)의 `playtest.csv`에 한 줄이 추가됩니다.
  - 열: `tester,stage,result,moves,undos,restarts,seconds,stars,time`
  - `result` 값

    | 값 | 뜻 |
    |---|---|
    | `clear` | 클리어 |
    | `left` | 클리어하지 않고 다른 스테이지로 이동 |
    | `reset` | 시도 도중에 "다음 테스터"를 누름 |
    | `pause` | 앱이 백그라운드로 감 (홈 버튼, 전화 등). 돌아오면 같은 스테이지가 새 행으로 이어지고, 이어진 행의 걸음은 앞의 걸음까지 합친 값입니다. |
    | `quit` | 앱이 종료됨 |

  - 끝나지 않은 행(`left`, `reset`, `pause`, `quit`)의 걸음은 마지막 "처음부터" 이후의 걸음입니다. 아무것도 하지 않고 넘어간 시도(걸음·되돌리기·재시작이 모두 0)는 기록하지 않습니다.
  - 클리어 후 "다시 하기"는 재시작으로 세지 않고 새 시도로 기록됩니다.
  - 앱을 지웠다가 다시 설치하면 기록 파일과 테스터 번호가 모두 초기화됩니다. 개발자가 미리 해 본 기록을 없애고 1번부터 시작하려면 플레이테스트 전에 다시 설치하세요.

  - 테스터가 끝날 때마다 "기록 보기" 화면을 사진으로 찍어 두면, CSV를 꺼내지 못해도 숫자가 남습니다.
- **테스터가 쓰는 조작** (설명하지 않습니다. 관찰할 때 참고용)
  - 이동: 스와이프, 또는 옆 칸을 탭
  - "되돌리기 N": 한 걸음 취소. 시도당 3회
  - "처음부터": 오른쪽 위. 판을 처음으로 되돌림. 무제한이며 되돌리기도 3회로 다시 채워짐

## 2. 진행 방법

### 2.1 원칙

- 규칙을 설명하지 않습니다. 조작 방법도 알려 주지 않습니다.
- 도와주지 않습니다. 힌트, 손가락으로 가리키기, 표정으로 알려 주기도 하지 않습니다.
- 막히면 최소 3분은 지켜봅니다.
  - `>` 버튼은 다음 스테이지가 열려 있을 때만 쓸 수 있습니다. 막히면 다음 스테이지로 못 넘어가니, 5분 넘게 막히면 그 자리에서 종료하고 기록합니다.
- 테스터가 하는 말과 머뭇거리는 곳을 그대로 적습니다. 해석은 나중에 합니다.
- 테스터가 바뀔 때마다 "다음 테스터"를 누릅니다.
- 앱을 끄지 않도록 합니다. 앱이 백그라운드로 가면 그 판은 `pause`로 기록되고, 돌아오면 새 행으로 이어서 기록됩니다.

### 2.2 읽어 줄 대본

**시작할 때**

> 색을 섞는 퍼즐이에요. 생각나는 걸 말하면서 해 주세요.
>
> 저는 옆에서 보기만 하고, 질문에는 대답하지 않을게요. 게임을 시험하는 거지, 실력을 보는 게 아니에요.

**테스터가 질문할 때**

> 지금 어떻게 하면 될 것 같아요? 생각하는 대로 해 보세요.

**말이 없어졌을 때**

> 지금 무슨 생각 하고 있어요?

**3분 넘게 막혔을 때** (`>` 버튼이 열려 있는 경우)

> 원하시면 다음 스테이지로 넘어가도 돼요.

**5분 넘게 막혔고 넘어갈 수 없을 때**

> 여기까지 할게요. 많이 도움이 됐어요.

(그 스테이지 메모에 "5분 초과 종료"라고 적습니다.)

**끝났을 때**

> 고마워요. 몇 가지만 물어볼게요. (4절 질문으로)

### 2.3 테스터 한 명의 순서

1. 1번 스테이지 화면인지 확인 (첫 테스터 전에는 사전 점검대로 "다음 테스터"로 비워 둡니다)
2. 폰을 건네고 시작 대본 읽기
3. 관찰하며 3절 기록표 채우기
4. 13번을 클리어하거나 중단하면 4절 질문
5. 스테이지 이름 길게 누르기 → "다음 테스터"를 두 번 눌러 마무리. 그래야 이 사람의 마지막 판까지 기록되고, 다음 사람 준비도 끝납니다. **마지막 테스터도 꼭 누릅니다.**
6. 다시 길게 눌러 "기록 보기" 화면 사진 찍기

> 클리어 창이 떠 있으면 스테이지 이름이 가려져서 길게 누를 수 없습니다. 13번을 클리어한 직후가 그런 경우입니다. 먼저 "다시 하기"를 눌러 창을 닫은 뒤 길게 누르세요. 이때 생기는 빈 시도는 기록되지 않습니다.

## 3. 사람별 기록표

## 4. 끝난 뒤 질문

테스터마다 물어보고 답을 그대로 적습니다. 4.1은 3절 기록표 바로 아래에 붙여서 함께 복사해 써도 됩니다.

## 6. 에이전트에게 넘기는 법

테스트가 끝나면 채운 기록지와, 꺼낼 수 있다면 `playtest.csv`를 함께 에이전트에게 넘기고 `docs/1011 에이전트 지시문.md`의 "지시문 7"을 붙여 맡깁니다. Android에서는 `playtest.csv`가 `Android/data/com.cameligarden.prototype/files/`에 있으며, USB로 연결해 복사하거나 `adb pull /sdcard/Android/data/com.cameligarden.prototype/files/playtest.csv`로 꺼낼 수 있습니다. iPhone에서는 이 파일을 꺼낼 수 없습니다(파일 공유 설정이 없음). 파일을 꺼내지 못하면 지시문의 자동 기록 파일 칸에 "없음"이라고 적고, 찍어 둔 "기록 보기" 사진의 숫자를 기록지에 옮겨 적어 주세요.
